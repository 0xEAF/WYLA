# WYLA

WYLA (What You're Looking At) tells you, well, what you're looking at, without any mods. 
Server-side plugin equivalent to Jade. (although it is not based on code from Jade, it is 100% inspired by it).

## Usage

Download this plugin from [Modrinth](https://modrinth.com/project/wyla) or [Hangar](https://hangar.papermc.io/xeaf/wyla).
After the first start, the plugin will have created a `WYLA` folder containing `config.yml` for configuration.
Most small servers like SMPs most likely do not need or want to edit it.

By default, every user has the WYLA bossbar indicating block/entity name and status (for entities, their health, for blocks, their breaking status).
Each user will be greeted first by a message informing them of this plugin, and proposing them to disable it for themselves with the command `/wyla`.
